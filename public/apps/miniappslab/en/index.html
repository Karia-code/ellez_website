What it does

A lightweight home for useful little apps.

MiniAppsLab is a Host App for web-based mini apps. It focuses on a simple local workflow instead of accounts, cloud dashboards, or subscriptions.

01

Import a project

Bring in a folder whose entry point is index.html, or paste a compact single-page HTML mini app.

02

Run on-device

Open your project inside an iOS web view. Core projects are designed to remain usable offline after import.

03

Keep versions

Save iterations such as V1, V2, and V3 so experiments do not overwrite the last working build.

04

Preview before replacing

Review an updated version before promoting it, with a clearer path to rollback when an edit goes wrong.

05

Launch from Home Screen

Use an Apple Shortcut to create a Home Screen entry that opens a project without first browsing through MiniAppsLab.

06

Local-first by default

No account or cloud workspace is required for the core workflow. Project files stay local by design; imported mini apps may still use the network if their own code requests external resources.

Workflow

From a folder to a usable mini app.

Import

Select a project folder or paste a small HTML app. MiniAppsLab validates the entry point before adding it.

Run

Test the project immediately on iPhone and confirm the interface behaves the way you expect.

Iterate

Save a new version, preview changes, compare your progress, and roll back when needed.

Pin

Create a Shortcut-based Home Screen entry so the mini app feels one tap away.

iPhone Home Screen

The important part: long-press the Shortcut.

iOS does not let MiniAppsLab silently create another app icon. Home Screen setup therefore uses Apple Shortcuts and only needs to be configured once for that project.

One-time setup
3 steps

After the shortcut is on your Home Screen, later MiniAppsLab project updates do not require you to recreate the Home Screen entry.

01

Save the project icon

In MiniAppsLab, open the project and choose Add to Home Screen. First save its App Icon to Photos for use by the system-managed shortcut.

02

Open Apple Shortcuts

Continue to Shortcuts. In the MiniAppsLab shortcut area, find the shortcut generated for the project you want to pin.

03

Long-press, then Add to Home Screen

Do not simply tap the shortcut—tapping runs the mini app. Long-press the project shortcut, choose Add to Home Screen, then finish the icon setup.

Why the extra step? The iPhone Home Screen entry is managed by iOS Shortcuts, not by MiniAppsLab itself. This keeps the workflow inside Apple's supported system behavior.
Technical scope

Web mini apps, not arbitrary native apps.

The distinction matters both technically and for App Store compliance.

Designed for

  • HTML, CSS, and JavaScript mini apps
  • Local tools, calculators, trackers, checklists, dashboards, and prototypes
  • Projects with an index.html entry point
  • Offline-capable experiences where project assets are bundled locally

Not positioned as

  • A way to install arbitrary native iOS binaries
  • A replacement for App Store distribution of full native apps
  • An unrestricted native API bridge for imported JavaScript
  • A cloud IDE or multi-user hosting service in the initial release
